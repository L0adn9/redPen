# Pilot: running RedPen on real APU briefs (Hassan, Sun from 12 PM)

## Collect (Fri–Sat)
- 10–20 real briefs + rubrics from past semesters, with **a lecturer's permission**. Our own past assignments are easiest.
- Remove names, emails and student data. Keep module codes only if the lecturer agrees; otherwise rename them (e.g. `MOD01`).
- Write a `clo-map.txt` for each (the CLOs are usually in the module descriptor or the brief).
- Upload each to `/RedPen/Assessments/<MODULE>/<ASSESSMENT>/` (brief last). **Never commit real briefs to the repo.**

## Run (Sun)
- Run each one through the Pro workflow. Run 3–5 of them through the Flash workflow too.
- Fill one row per run in `pilot-results-template.csv` (save as `pilot-results.csv`). Time each run.

## Stats for the deck/README (agree the list with Abdullah at Sync 3)
1. **X of N** briefs were passable by an unedited AI answer (HIGH).
2. **Y CLOs across Z modules** were no longer reliably evidenced.
3. **Flash vs Pro:** how many briefs got *more* exposed with the stronger model.
4. **Minutes per audit** (median) vs a lecturer's estimate for a manual audit + redesign (ask in the interview).
5. **Calibration** result (from Abdullah).

Use the same numbers everywhere (deck, README, video). Message Abdullah: **"Pilot stats done"**.
