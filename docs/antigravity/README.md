# How we used Google Antigravity

Antigravity is Google's agentic IDE: you give its agent a task in plain English and it reads the repo, plans, edits files and runs commands, with each change shown for review before it lands. We opened the `redPen` repo in it and used it on real parts of the prototype. Every change it made is in the repo.

**What we learned:** Swarm mode shows the orchestration best (agents handing work to each other by @mention, a monitor flagging stalls), but it is quota-heavy and needs file and command permissions approved up front. Antigravity was best at reading the whole repo quickly and at small, well-scoped changes it could verify itself (task 3 wrote and ran its own test). Long-running commands such as starting a web server are better done by hand.
